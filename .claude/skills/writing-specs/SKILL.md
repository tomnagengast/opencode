---
name: writing-specs
description: Use when drafting or updating specs before implementation planning begins - standardizes storage in `/specs`, filename format, and resource organization so specs stay discoverable and consistent
---

All specs should be saved to the `/specs` directory.
Specs should be named using `/specs/<YYYY-MM-DD>-<slug>.md`.
If a spec requires additional resources or files, add them to a directory with the same name as the spec withing the `/specs/resources` directory, ex: `/specs/resources/<YYYY-MM-DD>-<slug>/<resource>.md`.
When provided a link to a document, save it to the specs resources directory.
